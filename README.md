# Chemical Manufacturing Enterprise AI Operating System

An Enterprise AI Operating System designed for the Chemical and Polymer Manufacturing Sector.

## Key Capabilities

- **Executive Command Center**: Unified cross-plant dashboard with live KPIs, AI agent telemetry, programme ROI tracking, and executive approval queues.
- **Business Operations**: 39 chemical manufacturing department workspaces, task management, CAPA approvals, SOP compliance, and workflow execution.
- **AI & Automation**: Central hub managing 58 autonomous AI agents, 12 department copilots, n8n-compatible workflow builder, prompt templates, and AI model registry.
- **Knowledge & Documents**: Enterprise search across vector store, company AI brain, MSDS, TDS, contracts, and SOP repositories.
- **Insights & MIS Reporting**: Financial savings analytics, cycle-time trends, department adoption curves, and automated MIS pack downloads.
- **Platform Administration**: Role-based access control (RBAC), SSO authentication, audit logging, system health monitoring, and enterprise governance.

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
